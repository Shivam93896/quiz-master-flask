# Quiz Master - Flask Web Application

Quiz Master is a web-based quiz management application built using Flask. It allows an admin to manage subjects, chapters, quizzes, and questions, while users can register, attempt quizzes, and view their scores.

## Features

### Admin Features
- Admin login
- Add, edit, and delete subjects
- Add, edit, and delete chapters
- Create and manage quizzes
- Add and manage quiz questions
- View users
- View quiz summary charts

### User Features
- User registration and login
- View available quizzes
- Attempt quizzes
- Submit answers
- View scores and performance

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2 Templates
- Matplotlib for charts
